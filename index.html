📜 호그와트 연대기 시스템 안내

1. 90% 숨겨진 기질 + 10% 선택 시스템 제1권 시작 시 포켓몬의 성격과 개체값처럼 12가지 성격과 4대 기질이 비공개로 결정됩니다. 입학 전 3개월의 선택과 합쳐져 기숙사가 배정되며, 뻔한 선택지 없이 진짜 살아있는 이야기를 겪게 됩니다.
2. 7년 대장정 멀티 페이지 구조 이 메인 로비(index.html)와 각 학년 파일(year1.html ~ year7.html)을 같은 폴더에 모아 Netlify Drop이나 GitHub Pages에 올리면, 하나의 완성된 웹 게임 홈페이지로 자동 연동됩니다.
3. 태블릿 앱처럼 즐기기 패드 브라우저에서 홈페이지를 연 뒤 [홈 화면에 추가]를 누르면 주소창 없는 전체 화면 게임 앱처럼 쾌적하게 플레이할 수 있습니다.
